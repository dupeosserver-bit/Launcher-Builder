# Launcher Builder

Desktop tool for Minecraft content creators who run community SMP series.

The creator builds a modpack (Forge, NeoForge or Fabric) in Launcher Builder and exports a branded launcher (.exe) for their players.

## Player launcher
- Sign in with your own Microsoft account (official OAuth flow). We never ask for or store passwords; refresh tokens are encrypted locally with the OS keychain.
- Verifies Minecraft Java Edition ownership before playing.
- Installs Java, Minecraft, the mod loader and the creator's mods, then starts the game.
- Edit basic Minecraft options, keybinds and your skin without opening the game.

## Requirements
- Windows 10/11
- A Microsoft account that owns Minecraft Java Edition

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.
